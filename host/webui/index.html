Spectra settings

Every option is compile-time in the sketch, so applying them rebuilds MidiFighterSpectra locally with the new values and flashes it over DFU alt 0. Save alone keeps them for the next apply.

Application backup

Reads the running application area over DFU (alt 0). The file can be flashed back from the Restore tab.

Full flash backup

Reads all 512 KiB raw over DFU (alt 1, read-only). For archival: restoring a raw dump needs the Pico ROM flow and is not offered here.

Restore an application backup

Flashes the selected application backup over DFU (alt 0). The bootloader checks the image and writes its directory last, so an interrupted restore leaves the pad in the bootloader instead of half-flashed.

Upload application firmware

Pick a built app-area .bin (a directory + app.bin + cfg_tool.bin, e.g. work/sketch/…/MidiFighterSpectra.bin). The file is checked on arrival and again before flashing.

Bootloader update (advanced)

This rewrites the bootloader through DFU alt 2. The package is verified before the two sector-0 pointer writes — the riskiest windows in the whole system. Keep the USB cable connected.
